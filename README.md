# Project_repo
Hospital Appointment Scheduler (PS No. 77)Welcome to the Hospital Appointment Scheduler, a command-line clinic management tool built in Python 3. Designed for clinic receptionists, this application streamlines day-to-day appointment workflows—booking, viewing, rescheduling, and cancelling patient visits—while enforcing clinic scheduling rules and date/time validation.Table of ContentsProject OverviewKey Features & Business RulesProject StructureGetting Started & Running the AppInteractive Walkthrough & Menu GuideTest Cases & Expected OutputsDesign & Architecture NotesFuture EnhancementsProject OverviewIn a busy outpatient clinic, receptionists need a fast, dependable way to coordinate appointments without double-booking doctors or accepting invalid dates and times. This project implements a single-file Python 3 console application that stores all appointments in an in-memory dictionary keyed by auto-generated appointment IDs (A101, A102, ...).Core Concepts UsedDictionaries (dict): Fast $O(1)$ lookup, update, and deletion of appointments by ID (A101, A102, etc.).Datetime Module (datetime, time): Strict parsing and validation of dates (DD-MM-YYYY) and times (HH:MM).Modular Functions: Clean separation of concerns across input parsing, slot validation, conflict checking, ID generation, and CRUD operations.CRUD Operations:Create: Book new appointments (1).Read: View all active appointments and total count (2).Update: Reschedule existing appointments to a new valid date and time (3).Delete: Cancel appointments by ID (4).Key Features & Business RulesClinic Doctors: Supports Dr. Mehta and Dr. Rao.Auto-Generated IDs: Starts at A101 for the first booked appointment, incrementing sequentially (A102, A103, ...).30-Minute Slot Window: Accepts only 30-minute boundary times (:00 or :30) from 09:00 (inclusive) to 16:30 (inclusive).Double-Booking Prevention: A doctor cannot hold two overlapping/identical appointments at the same date and time.Strict Date Validation: Enforces the DD-MM-YYYY format using datetime.strptime, automatically rejecting impossible calendar dates such as 31-11-2026 (November has 30 days) or malformed strings.Continuous Console Loop: Displays the menu repeatedly until the user chooses 5 (Exit).Project Structure.

Getting Started & Running the AppPrerequisitesPython 3.8+ (uses only the Python Standard Library—no external pip packages required).Run from Terminal / Command Promptpython3 appointment_scheduler.py
(On Windows, you can also use python appointment_scheduler.py.)Interactive Walkthrough & Menu GuideWhen you launch the program, you see an interactive menu:--- Hospital Appointment Scheduler ---
1. Book Appointment
2. View All Appointments
3. Reschedule Appointment
4. Cancel Appointment
5. Exit
How to Use Each OptionBook Appointment (1): Prompts for Patient, Doctor, Date (DD-MM-YYYY), and Time (HH:MM). Validates inputs, checks for conflicts, assigns the next ID (A101, A102, ...), and prints a confirmation line.View All Appointments (2): Lists every active appointment in ID | Patient | Doctor | Date Time format, followed by Total appointments: <count>.Reschedule Appointment (3): Asks for the Appointment ID (e.g., A101), New date, and New time. Validates the new slot and checks doctor availability (ignoring the appointment's own current slot) before updating.Cancel Appointment (4): Asks for the Appointment ID and removes it from the schedule if found.Exit (5): Cleanly terminates the loop and exits the program.Test Cases & Expected OutputsAll test cases below assume a fresh run starting from an empty schedule (A101 first ID):Test Case 1: Normal InputInput:Menu option: 1Patient: Ravi SharmaDoctor: Dr. MehtaDate: 15-11-2026Time: 10:00Expected Output:Appointment booked. Design & Architecture NotesID Counter Separation: Tracking id_counter separately from len(appointments) ensures that cancelling an appointment (like A102) never reuses or collides with previously issued IDs.Conflict Check on Reschedule: is_doctor_available(..., ignore_id=appt_id) allows rescheduling an appointment without falsely conflicting with its own existing slot.Input Hygiene: .strip() and .upper() / case-insensitive doctor matching reduce user friction while keeping stored data clean and consistent.Future EnhancementsPersist appointments to a JSON or CSV file across sessions.Add daily schedule filtering by doctor or date.Support additional clinic doctors via configuration.
